动态特效画廊

手写 Canvas 粒子场、指针驱动的 3D 倾斜 与光晕反馈， 全部由原生 CSS 与 JavaScript 构成，不依赖任何框架与外部资源。

向下滚动
01 / 倾斜卡片

随鼠标倾斜的 3D 卡片

把指针在卡片内的相对位置换算成 rotateX 与 rotateY，内层标题、正文与光斑分布在不同 Z 轴上， 转动时自然产生前后错位；指针离开后交给 CSS 过渡完成回弹。

LAYER 01

视差层级

标题位于 40px、正文位于 18px 的 Z 轴深度，倾斜时层次被拉开。

LAYER 02

指针换算

以卡片左上角为原点，横向偏移驱动 Y 轴旋转，纵向偏移驱动 X 轴旋转。

LAYER 03

平滑回弹

指针移动时切换为线性短过渡，离开后移除内联变量，交给缓动曲线回位。

LAYER 04

触屏降级

没有精确指针或系统开启减少动态效果时，卡片保持稳定的静态呈现。

02 / 磁性反馈

磁性按钮与光晕跟随

悬停时一层径向高光跟随指针移动，按下时以点击坐标为圆心扩散水波纹；坐标通过 CSS 变量 --mx 与 --my 传递，绘制完全交给合成层。

  • 指针坐标实时写入 CSS 变量，径向渐变在 GPU 上完成合成。
  • 每次点击生成独立的波纹元素，动画结束后自动移除，不留残余节点。
  • 键盘触发时波纹落在按钮中心，触屏设备跳过光晕跟随。
03 / 滚动联动

滚动即叙事

IntersectionObserver 让每个区块在进入视口时淡入上移，顶部的进度条随阅读位置填充， 首屏标题则按滚动距离做轻微视差位移。

170 个

粒子数量按画布面积自动裁剪，设备像素比上限锁定为 2。

1 条

所有绘制共用一条 requestAnimationFrame 循环，页面隐藏时立即暂停。

0 依赖

没有任何外部字体、图片与动画库，断网状态下依旧完整呈现。
