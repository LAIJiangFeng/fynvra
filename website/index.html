03常见问题FAQ

装之前，先看看这些。Before you install.

更完整的说明见For the full picture, read the 使用文档user guide。.

收费吗？Is it free?

Fynvra 本身免费开源，使用 Apache-2.0 许可证。模型调用的费用和额度来自你自己的服务商账号。

Fynvra itself is free and open source under Apache-2.0. Model usage is billed by whichever provider account you connect.

没有 git 的项目能用吗？Can I use it without git?

能。非 git 目录按原地模式工作：不建 worktree，Worker 直接在目录里修改，审查时列出它汇报的改动文件。并行的 Worker 会共用同一个目录，建议一次只派一个任务。

Yes. Folders without git run in in-place mode: no worktrees, workers edit the folder directly, and review lists the files they reported. Parallel workers would share the folder, so dispatch one task at a time.

支持哪些平台？Which platforms are supported?

Windows x64 和 macOS（Intel / Apple Silicon）。Linux 有 AppImage 构建配置，但暂未纳入自动发布与更新。

Windows x64 and macOS (Intel and Apple Silicon). Linux has an AppImage build config but isn't part of automated releases or updates yet.
