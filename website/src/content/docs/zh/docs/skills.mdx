技能是带 `SKILL.md` 的目录。Fynvra 只登记它的位置和元数据，不复制技能文件；在角色里勾选后，使用该角色的会话才能调用。

<span id="skills-register" />

## 扫描或添加目录

1. ### 打开技能页

   「设置 → 技能」。空状态和页头都能进入扫描或添加目录。

2. ### 扫描本机（可选）

   点「扫描本机」，Fynvra 会找已知位置中含 `SKILL.md` 的技能目录。勾选要登记的项，点「登记所选」；已登记的会标出。

3. ### 添加自定义目录

   点「添加目录」，在系统目录选择器里选技能目录。主进程读取并校验 `SKILL.md`，成功后列表出现技能名称、描述和路径。

4. ### 确认已启用

   列表里的开关控制这个技能是否可用。已停用的技能显示「已停用」。

<span id="skills-manage" />

## 启停、移除与分配给角色

列表里的开关随时可以切换。垃圾桶按钮只从 Fynvra 注册表移除该技能，不删除磁盘上的文件。移除后，引用它的角色会显示「已移除」。

要让某个角色使用技能，到「设置 → 角色」打开该角色，在「技能」多选里勾选。角色保存后，新启动的会话加载这些技能；角色没有勾选的技能不会注入。

<span id="skills-notes" />

## 注意

技能来自本机目录，Fynvra 不负责更新或联网下载。目录被移走后，技能会读取失败，需要重新添加。扫描结果只登记含 `SKILL.md` 的目录。
