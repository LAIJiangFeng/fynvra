<span id="providers" />

所有模型都来自「设置 → 模型服务」。可以选预设，也可以填自定义 OpenAI 兼容地址；每个服务有独立的 API Key、模型列表和推理开关。

<span id="providers-add" />

## 添加一个服务

1. ### 打开模型服务

   按 <kbd>Ctrl</kbd>+<kbd>,</kbd>（macOS <kbd>⌘</kbd>+<kbd>,</kbd>）打开设置，点左侧「模型服务」。

2. ### 点「添加服务」并选来源

   下拉里是预设服务；最后一项是「从本机导入…」。预设会带好名称、协议和官方地址。

3. ### 填写连接信息

   名称、API 协议、Base URL、API Key。官方地址可以留空；自定义地址必须以 `http://` 或 `https://` 开头。

4. ### 添加模型

   点「拉取模型列表」从服务端选择，或在下方手动输入模型 id 后点「添加」。每个模型旁的「推理」开关决定会话里能否选思考档位；内置目录能判定的模型会显示只读标记。

5. ### 保存并启用

   检查底部的「启用」开关，保存。卡片上的开关也可以随时停用或恢复，停用不会丢 Key。

<span id="providers-test" />

## 测试、编辑与删除

卡片上的「测试连接」会显示耗时，以及服务端返回了多少个模型；没有 API Key 时按钮禁用。编辑会打开同一个表单，已保存的 Key 只显示末 4 位，留空表示不修改；也可以点「清除 key」。

删除前会提示「引用它的角色需重选模型」。确认删除后，角色里仍指向这个服务的模型会显示不可用，需要到「设置 → 角色」重新选模型。

<span id="providers-import" />

## 从本机导入

「从本机导入…」会读取 Claude Code、Codex、CC Switch 里已有的服务。没有 API Key 或自定义地址的配置不会出现。选择来源后逐个确认要导入的服务；每个服务还可以选择要加入的模型。

<span id="providers-keys" />

## 密钥怎么存

<aside class="docs-callout">

**密钥**

API Key 的明文只在主进程使用，界面上回显成掩码。它保存在本机配置文件里，不是加密凭证库。不要把应用数据目录、配置导出或带密钥的日志发给别人。删除一个服务后，引用它的角色需要重新选择模型。

</aside>
