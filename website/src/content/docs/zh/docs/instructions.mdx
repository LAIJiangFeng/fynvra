<span id="instructions" />

指令文件是本机的 CLAUDE.md / AGENTS.md 类文本，会注入会话。全局同一时间只启用一份；角色可以指定其他文件，或选择不使用。

<span id="instructions-add" />

## 添加或导入

1. ### 打开指令文件页

   「设置 → 指令文件」。页头有「从本地应用导入」和「添加指令」。

2. ### 导入已有文件

   点「从本地应用导入」，Fynvra 扫描已知位置的指令文件。勾选后导入。导入是链接形式：每次启动会话时读取源文件，Fynvra 不会修改源文件。

3. ### 或新建本地副本

   点「添加指令」，填名称和内容，保存为 Fynvra 的本地副本。也可以从「选择 .md 文件…」读取内容。支持 Markdown 文本，最大 2 MiB。

4. ### 启用一份

   列表里的开关控制全局启用。启用一份会自动关闭其余，因为同一时间只有一份全局生效。

<span id="instructions-activate" />

## 角色如何选择

角色编辑器的「指令文件」可以选择「跟随全局」「不使用」或某个具体文件。具体文件会覆盖全局选择，即使该文件的全局开关已关闭也会被读取。更改在会话下次启动时生效。

列表会显示当前生效的字符数、来源和本地副本/链接类型；链接文件缺失或不可读时会警告，并且不会注入。移除条目只从 Fynvra 删除记录，不会删除或修改磁盘上的原始文件。

<span id="instructions-limits" />

## 限制

本地副本最大 2 MiB；大段文本不写进 `settings.json`。链接文件每次启动会话读取，源文件改动会在下次会话生效；本地副本要在这里编辑后保存。
