<span id="composer" />

输入框在会话底部。左边是图片、模型和审批胶囊，右边是发送或停止；运行中发送会排队。输入框下方一条状态栏汇总 tokens、费用、审批档位、分支和模型。

<span id="composer-send" />

## 发送、排队与停止

在输入框里写消息，按 <kbd>Enter</kbd> 发送，<kbd>Shift</kbd>+<kbd>Enter</kbd> 换行。消息为空且没有图片时发送按钮不可用。第一次发送会启动这一回合，时间线出现你的消息和 Agent 的回复、思考与工具调用。

运行中发送按钮变成「排队」，消息进入输入框上方的队列；点「停止」或按 <kbd>Esc</kbd> 结束当前回合。队列里每条消息可以「立即发送」或从队列移除，<kbd>Ctrl</kbd>+<kbd>S</kbd> 可以把最近一条排队的消息立即插入当前回合。

底部状态栏实时累计输入/输出 tokens 和费用；有分支时显示当前分支，悬停可看 cwd。

<span id="composer-model" />

## 切换模型与思考档位

点输入框左下角的模型胶囊（显示「服务 · 模型 · 思考档位」），打开可搜索的模型列表。输入服务名或模型名过滤，点一项即可切换；弹层底部是当前模型的思考档位。也可以按 <kbd>Ctrl</kbd>+<kbd>M</kbd> 打开同一个选择器，或点底部状态栏右侧的模型名。

运行中不能切换模型，列表项会禁用；等这一轮结束再切。

<span id="composer-approval" />

## 切换审批档位

模型胶囊旁边是审批胶囊，点开可在「全程审批 / 自动接受编辑 / 完全放行」之间单选，或按 <kbd>Shift</kbd>+<kbd>Tab</kbd> 循环切换。角色设置里的审批档位是新建会话的默认值；会话里切换后，下一次需要审批的工具调用起生效。

需要你确认的操作会出现在输入框上方的审批条，按钮是「拒绝 / 本会话都允许 / 允许」。跨工作区的待审批请求还会在窗口顶部出现提示条，点「查看并处理」集中处理。详见 [审批](/zh/docs/approval/)。

<span id="composer-images" />

## 图片、历史和草稿

点输入框左侧的图片按钮，或直接按 <kbd>Ctrl</kbd>+<kbd>V</kbd> 粘贴图片。支持 PNG、JPEG、GIF、WebP，单条消息最多 10 张、单张不超过 20 MB、合计不超过 50 MB。缩略图挂在输入框顶部，右下角 × 可移除；只有图片也能发送。

输入框为空或光标在视觉第一行时按 <kbd>↑</kbd> 取上一条发过的消息，在最后一行按 <kbd>↓</kbd> 取下一条；<kbd>Esc</kbd> 回到原来的草稿。翻到的内容一编辑就成为新草稿。切换会话时草稿按会话保留，切回来还在。
