右栏固定有三个标签：文件、任务、改动。文件树和 diff 条目在右栏选，实际内容在中间打开；任务看板在右栏展开，任务详情以抽屉覆盖右栏。

<span id="panels-layout" />

## 右栏与标签

右栏顶部有「文件 / 任务 / 改动」三个标签，任务标签旁显示当前 run 的任务数量。左边缘是分隔条：拖动可调宽，双击恢复默认宽度；分隔条聚焦时用 <kbd>←</kbd> / <kbd>→</kbd> 也可以调整。

快捷键：<kbd>Ctrl</kbd>+<kbd>B</kbd> 显示或隐藏右栏，<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> 显示或隐藏左栏。macOS 上把 Ctrl 换成 ⌘。

<span id="panels-files" />

## 文件：目录、编辑与终端

在「文件」标签里展开目录，点文件名会在中间新增一个标签并打开文件。刷新按钮重新读取目录和未修改的文件。文本文件可直接编辑，Markdown 可切换编辑 / 预览 / 双栏；图片可预览。支持 UTF-8 文本（256 KiB 内）和 PNG / JPEG / GIF / WebP 图片（2 MiB 内）。

保存用编辑器的「保存」或 <kbd>Ctrl</kbd>+<kbd>S</kbd>（macOS <kbd>⌘</kbd>+<kbd>S</kbd>）；未保存的标签带圆点，关闭或重新读取前会询问保存、放弃或取消。右键文件或目录可新建文件 / 文件夹、复制、复制路径、创建副本、在文件资源管理器中显示、重命名、删除（移到系统回收站）。

中间标签条最左侧固定「对话」，右边的 **+** 可选择新开对话或终端。切换文件或终端时对话不会卸载；关闭仍在运行的终端会先确认。

<span id="panels-changes" />

## 改动：未提交、已提交与 diff

打开一个会话后，「改动」默认读取当前会话的工作区：顶部显示分支、相对提交、变更统计，下面是「未提交的更改」和「已提交的更改」两棵文件树，以及提交列表。窗口重新获得焦点或会话结束后会自动刷新，也可以点刷新按钮。

点文件树里的文件，会在中间打开 diff 标签；按状态显示新增、修改、删除、重命名或复制。无 git 工作区会显示「无 git」，没有 diff 可看。

从任务详情点「查看改动」时，这里切到该任务的「任务历史审查」；点「查看当前对话改动」回到当前会话。worktree 已清理时会标明这是清理前的改动。
