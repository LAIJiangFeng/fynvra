下面是默认按键。macOS 上把 Ctrl 换成 ⌘。所有动作都能在「设置 → 快捷键」里查看和重绑；冲突的按键不会保存。

<span id="shortcuts-app" />

## 应用快捷键

| 操作 | 按键 |
| --- | --- |
| 新建会话 | <kbd>Ctrl</kbd>+<kbd>N</kbd> |
| 打开设置 | <kbd>Ctrl</kbd>+<kbd>,</kbd> |
| 显示或隐藏右侧面板 | <kbd>Ctrl</kbd>+<kbd>B</kbd> |
| 显示或隐藏左侧栏 | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> |
| 聚焦输入框 | <kbd>Ctrl</kbd>+<kbd>L</kbd> |
| 搜索会话 | <kbd>Ctrl</kbd>+<kbd>K</kbd> |
| 上一个 / 下一个会话 | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>[</kbd> / <kbd>]</kbd> |
| 选择模型 | <kbd>Ctrl</kbd>+<kbd>M</kbd> |
| 发送 | <kbd>Enter</kbd> |
| 换行 | <kbd>Shift</kbd>+<kbd>Enter</kbd> |
| 切换审批档位 | <kbd>Shift</kbd>+<kbd>Tab</kbd> |
| 停止当前回合 | <kbd>Esc</kbd> |
| 立即发送排队消息 | <kbd>Ctrl</kbd>+<kbd>S</kbd> |
| 上一条 / 下一条历史消息 | <kbd>↑</kbd> / <kbd>↓</kbd> |

<span id="shortcuts-rebind" />

## 改键

「设置 → 快捷键」分成「全局」和「输入框」两组。每行显示当前键和「改键」按钮；点改键后直接按下新组合键，<kbd>Esc</kbd> 取消。按键必须带 Ctrl / Alt / ⌘，或使用允许的输入框单键；与保留的编辑键或其他动作冲突时不会保存，并会说明冲突对象。

改动过的动作旁会出现「重置」，只恢复这一项；顶部「全部重置」恢复所有默认键。快捷键保存在本机设置里。

## 搜索文档

点顶部的搜索按钮，或按 <kbd>Ctrl</kbd>+<kbd>K</kbd>（macOS <kbd>⌘</kbd>+<kbd>K</kbd>）打开搜索，输入标题或正文关键词，查找当前语言的文档。用 <kbd>↑</kbd> / <kbd>↓</kbd> 在结果间移动，<kbd>Enter</kbd> 打开，<kbd>Esc</kbd> 关闭搜索并回到正文；也可以通过侧栏目录浏览文章。
