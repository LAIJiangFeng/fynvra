<span id="overview" />

Fynvra 是一个本地运行的多 Agent 编程工作台。你只和主 Agent 对话；它把需求拆成任务，交给各自的 Worker，再审查和合并。这一页先对应真实界面，告诉你每一块在哪里、下一步点哪里。

<span id="overview-layout" />

## 界面一眼看懂

窗口顶部是标题栏：左边开关左栏，右边是设置、主题和右侧面板。设置会覆盖整个窗口，按 <kbd>Esc</kbd> 或右上角的关闭按钮返回。标题栏下面分成三块。

<div class="docs-area-grid">

<div class="docs-area-card">

**左栏**

### 工作区 → 会话

“工作区”标题右侧的 **+** 挂入目录。每个工作区用左侧箭头展开会话；会话行显示状态点、角色徽标和更新时间。

</div>

<div class="docs-area-card">

**中间**

### 对话与文件标签

顶部标签条固定有「对话」。打开文件、终端或 diff 后出现新标签。对话里从上到下是标题、消息、审批条、输入框和底部状态栏。

</div>

<div class="docs-area-card">

**右栏**

### 文件 / 任务 / 改动

「任务」标签上显示当前编排的任务数。右栏左边缘可拖动调宽，双击恢复默认宽度。

</div>

</div>

> 第一次打开还没有工作区时，中栏只有「挂入目录」按钮，右栏会提示先选择工作区。挂入一个目录后，再新建会话。

<span id="overview-objects" />

## 五个词

- **工作区**

  挂进来的一个目录。有 git 时按仓库编排，每个任务用独立 worktree；没有 git 的目录显示「无 git」，按原地模式工作。

- **会话**

  一次和某个角色的对话。状态有空闲、运行中、等待审批、出错。会话记录保存在本机。

- **主 Agent**

  内置的 Orchestrator 角色。拆任务、派活、审查、合并，默认自己不改代码。新建会话时默认选它。

- **Worker**

  接到一个任务的 Agent。它在自己的 git worktree 里改代码，做完向主 Agent 汇报；无 git 时直接在挂入的目录里改。

- **收件箱**

  Worker 和主 Agent 之间的消息：提问、答复、指示、完成汇报。任务详情里能看到整条消息流；主 Agent 空闲时会被新消息唤醒。
