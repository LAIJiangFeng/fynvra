<span id="appearance" />

主题在标题栏或「设置 → 外观」切换；语言、Worktree 位置、会话归档、时间线显示等偏好集中在「设置 → 通用」。这些设置立即保存，不需要重启。

<span id="appearance-theme" />

## 主题

点标题栏的主题按钮，或到「设置 → 外观」，在「浅色 / 深色 / 跟随系统」中选一个。两处共用同一份设置，切换后立即生效。跟随系统时，系统主题变化会同步更新。

<span id="appearance-language" />

## 语言

到「设置 → 通用 → 语言」选择「跟随系统 / 简体中文 / English」。界面文案和会话里的角色描述会随之切换。这个官网文档页顶部的语言选择器会打开当前文章的对应语言版本，搜索也使用所选语言的文档。

<span id="appearance-general" />

## 通用偏好

「设置 → 通用」里还有：

- **Shell**：Windows 上分别设置 Agent 命令用的本地命令壳和终端 Shell；其他平台设置终端登录 Shell。新会话或新终端创建时生效。
- **Git 与命令代理**：沿用现有环境或手动填写无认证的 HTTP/HTTPS 代理；可以测试 GitHub API 和远程仓库连通性。
- **Worktree 位置**：选择自定义目录或恢复默认；「磁盘占用」列出每个工作区的 worktree 数量与大小。
- **会话**：闲置归档天数、归档时清理 worktree、归档多久后删除记录。
- **时间线**：精简只读工具、运行中展开文件改动、思考时展开、折叠历史轮次。
- **应用更新**：正式版显示当前版本、检查更新和安装状态；开发模式提示不检查更新。

<span id="appearance-notifications" />

## 通知

「设置 → 通知」可以开关桌面通知，并分别控制是否只在主 Agent 完成时通知、Worker 提问与审批请求是否通知，以及是否播放声音。改完可以发送一条测试通知确认系统权限。

<span id="appearance-usage" />

## 用量

「设置 → 用量」按今天 / 7 天 / 30 天 / 90 天统计预估费用、tokens、会话与消息数、活跃时长，并给出按角色、模型、工作区、时段和编排结果的分布。费用按记录的模型单价估算，只在这台电脑上计算。
