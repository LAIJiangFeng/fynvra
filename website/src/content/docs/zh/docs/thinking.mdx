<span id="thinking" />

思考档位决定模型在回答前想多深。它只在模型支持推理、并且该模型打开了推理时出现；不同模型提供的档位可能不同。

<span id="thinking-set" />

## 在哪里选

三个地方可以选同一份档位：输入框的模型选择器底部、新建会话弹层的模型下方、角色编辑器里的「思考档位」。选择器只列出当前模型自己支持的档位；模型服务上的「推理」没打开时，这个选项不会出现。

会话里切换档位后立即用于下一回合；运行中不能切模型，但思考档位按钮也会随模型一起禁用。

<span id="thinking-levels" />

## 档位含义

| 档位 | 含义 |
| --- | --- |
| off | 关闭思考 |
| minimal | 极少思考 |
| low | 少量思考 |
| medium | 适中，日常改代码用这个就够 |
| high | 深入思考 |
| xhigh | 更深入思考 |
| max | 最大思考。更慢，也更耗额度 |

<span id="thinking-source" />

## 没有档位信息时

某个模型在目录里没有档位信息时，界面会标「推断」或「兜底」：推断表示按同目录的模型估计，兜底表示目录里没有这个模型、按协议给一组通用档位。悬停徽标会写明依据。
