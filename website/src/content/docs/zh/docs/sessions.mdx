<span id="sessions" />

会话是一次和某个角色的对话。新建时选角色、模型和思考档位；之后在左栏切换，或在同一个工作区里搜索标题。运行中的会话会明确显示状态。

<span id="sessions-create" />

## 新建会话

1. ### 选择入口

   展开工作区后，点「会话」标题右侧的 **+**；或在中间点「新建会话」。两者打开同一个弹层。

2. ### 选角色

   列表来自「设置 → 角色」，默认选 Orchestrator。只想让一个 Agent 直接干活时选 Worker；自定义角色也可以在这里选。

3. ### 选模型和思考档位

   模型下拉按服务分组。模型支持推理时，下方会出现思考档位；不支持或服务不可用时会给出提示。

4. ### 点「创建」

   会话创建后自动选中，左栏出现新行，中间进入对话视图。没有可用模型服务时，先回「设置 → 模型服务」添加。

<span id="sessions-switch" />

## 切换和搜索

在左栏展开工作区后点会话行即可切换。中间的会话标题栏会显示状态点、标题、角色徽标和当前分支；底部状态栏显示 token、费用、审批档位、分支和模型。

快捷键：<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>[</kbd> 上一个会话，<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>]</kbd> 下一个会话；<kbd>Ctrl</kbd>+<kbd>K</kbd> 打开会话搜索。macOS 上把 Ctrl 换成 ⌘。

<span id="sessions-status" />

## 状态与限制

| 状态 | 含义 | 你能做什么 |
| --- | --- | --- |
| 空闲 | 当前回合已结束 | 继续输入、切模型、归档或删除 |
| 运行中 | Agent 正在执行这一回合 | 发送会进入排队；可停止；不能切模型、归档或删除 |
| 等待审批 | 有工具调用需要你确认 | 在输入框上方的审批条处理；相关任务暂停 |
| 出错 | 回合或记录读取失败 | 看时间线上方的错误提示；修正后重新发送 |

运行中切换模型会被拒绝；等这一轮结束再切。归档和删除也会等运行结束。

<span id="sessions-worker" />

## 查看 Worker 会话

主 Agent 派发后，Worker 会话会登记在同一个工作区的会话列表里，角色徽标显示 Worker。点开它可以查看它收到的任务、消息和工具调用；任务级输出、尝试记录和改动在右栏「任务」的任务详情里。

要调整任务，建议在主 Agent 的会话里说明，让任务书、审查和合并保持一致。

<span id="sessions-manage" />

## 归档与删除

把鼠标移到会话行上，右侧出现归档和删除按钮。归档后会话移到列表底部的「已归档」，点开分组可以恢复。删除会话会把它从列表移除，底层记录文件保留；运行中的会话两个操作都不可用。

在「设置 → 通用 → 会话」里可以设置闲置多少天后自动归档、归档时是否清理已合并且干净的 worktree，以及归档多少天后删除记录。
