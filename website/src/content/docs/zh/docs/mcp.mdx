MCP 服务器给 Agent 增加外部工具。可以在「设置 → MCP」手动添加本地进程或远程服务，也可以从本机已有配置导入。和技能一样，要在角色里勾选后才会被会话加载。

<span id="mcp-add" />

## 添加服务器

1. ### 打开 MCP 页

   「设置 → MCP」，点「添加服务器」。

2. ### 填名称和传输方式

   传输方式有「本地进程（stdio）」「远程（Streamable HTTP）」「远程（SSE）」。

3. ### 配置连接

   stdio 填启动命令、参数（一行一个）和环境变量；远程填 URL 和 Header。带密钥的值只在本机保存，列表里只显示键名。

4. ### 启用并保存

   确认「启用」开关后保存。列表卡片显示传输方式、打码后的命令或 URL，以及已保存的密钥键名。

<span id="mcp-import" />

## 从本机导入

点「从本机导入…」，Fynvra 会扫描 Claude Code、Codex、Grok CLI、Gemini CLI、Cursor、VS Code、OpenCode 和 CC Switch 的 MCP 配置。可以只勾选需要的来源；扫描结果先列成候选，确认后再导入。没有找到会直接提示；URL 或命令相同的已有项会标记为重复。

<span id="mcp-manage" />

## 启停、编辑、删除与分配

卡片上的开关控制启用状态；铅笔进入编辑；垃圾桶会让你确认，删除后引用它的角色将不再加载它。要分配给角色，到「设置 → 角色」的「MCP 服务器」多选里勾选，保存后新会话生效。

MCP 工具调用也会经过审批：在「全程审批」和「自动接受编辑」下仍要你确认，「完全放行」下按常规工具处理。工具能力仍受角色的工具策略限制。
