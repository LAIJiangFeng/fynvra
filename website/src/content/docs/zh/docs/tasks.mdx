右栏「任务」按 run 展示任务卡片，点击卡片打开任务详情。详情里能看任务书、依赖、每次尝试、对话消息和最新一次 Worker 输出，也能跳到该任务的改动。

<span id="tasks-view" />

## 任务列表怎么读

打开右栏「任务」标签。顶部一行是当前 run 的目标、创建时间、已完成数量和进度条；有已放弃任务时可以点开查看。存在多个 run 时，顶部会出现切换下拉框。

下面按状态分组：待开始、进行中、待验收、已完成、失败、已放弃；组标题可折叠，已放弃组默认收起。卡片显示任务标题、角色徽标、分支、运行时长、尝试次数、依赖和最新一条消息。点卡片打开详情。

<span id="tasks-detail" />

## 任务详情

详情以抽屉覆盖右栏，按 <kbd>Esc</kbd> 或左上角返回箭头关闭。头部有状态、角色和分支；任务处于「待验收」或「已完成」且使用 git 时，右上角有「查看改动」。

正文依次是可折叠的「任务书」、依赖任务、尝试时间线、消息流和最新一次尝试的 Worker 输出。点依赖任务可以直接切到那个任务；历史尝试会标出成功/失败、起止时间、摘要和改动文件。

抽屉是只读的。要修改任务或要求合并 / 打回，回到主 Agent 的对话里说。

<span id="tasks-output" />

## Worker 输出

任务详情底部是「worker 输出」：等宽文本，自动跟随到底部。向上滚动会停止跟随；点暂停会把画面冻结在当时，同时后台继续拉取。暂停按钮旁显示新增字符数，点「继续」或回到底部按钮一次补齐。

只显示最新一次尝试的完整输出；更早的尝试在上面的尝试时间线里。输出被截断时会标出前面未保留的字符数。读取失败可以重试；任务没有输出时显示「没有输出」或「等待输出…」。

<span id="tasks-review" />

## 跳到改动验收

点「查看改动」会关闭抽屉，切到右栏「改动」，并载入这次派发的任务历史审查。点「查看当前对话改动」回到当前会话的改动。任务合并并清理 worktree 后，历史改动仍可查看，页头会说明这是清理前的快照。

只想看 Worker 本身的消息时，也可以从左侧会话列表打开它的 Worker 会话。
