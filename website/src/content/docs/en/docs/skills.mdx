A skill is a folder with a `SKILL.md`. Fynvra registers its location and metadata without copying the files; a session can use it only when its role selects it.

<span id="skills-register" />

## Scan or add a folder

1. ### Open Skills

   Go to Settings → Skills. The empty state and page header both offer scanning or adding a folder.

2. ### Scan this computer (optional)

   Click Scan local. Fynvra looks in known locations for skill folders containing `SKILL.md`. Select the entries to register and click Register selected; already registered skills are marked.

3. ### Add a custom folder

   Click Add folder and choose a skill directory in the system dialog. The main process reads and validates `SKILL.md`; the list then shows the name, description, and path.

4. ### Confirm it is enabled

   The switch on each row enables or disables the skill. Disabled skills show a Disabled badge.

<span id="skills-manage" />

## Toggle, remove, and assign

Use the switch any time. The trash button removes the skill from Fynvra’s registry only; it does not delete files from disk. Roles that referenced it then show it as removed.

To let a role use a skill, open it under Settings → Roles and select the skill in the Skills list. After saving the role, newly started sessions load those skills; skills not selected by the role are not injected.

<span id="skills-notes" />

## Notes

Skills come from local folders; Fynvra does not update or download them. If a folder is moved, the skill cannot be read and must be added again. Scanning registers only folders that contain `SKILL.md`.
