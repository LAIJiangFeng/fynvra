These are the defaults. On macOS, Ctrl is ⌘. Every action can be viewed and rebound under Settings → Shortcuts; conflicting keys are not saved.

<span id="shortcuts-app" />

## App shortcuts

| --- | --- |
| New session | <kbd>Ctrl</kbd>+<kbd>N</kbd> |
| Open settings | <kbd>Ctrl</kbd>+<kbd>,</kbd> |
| Toggle the right panel | <kbd>Ctrl</kbd>+<kbd>B</kbd> |
| Toggle the sidebar | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> |
| Focus the composer | <kbd>Ctrl</kbd>+<kbd>L</kbd> |
| Search sessions | <kbd>Ctrl</kbd>+<kbd>K</kbd> |
| Previous / next session | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>[</kbd> / <kbd>]</kbd> |

| New line | <kbd>Shift</kbd>+<kbd>Enter</kbd> |

| Previous / next history message | <kbd>↑</kbd> / <kbd>↓</kbd> |

<span id="shortcuts-rebind" />

## Rebind

Settings → Shortcuts is split into Global and Composer. Each row shows the current chord and a Rebind button; click it and press the new combination, or <kbd>Esc</kbd> to cancel. A chord must include Ctrl / Alt / ⌘ or be an allowed bare composer key. Conflicts with reserved editing keys or another action are rejected with the conflicting name.

Changed actions gain a Reset button for that action; Reset all at the top restores every default. Bindings are stored in local settings.

<span id="shortcuts-docs" />

## Search the docs

Click Search in the top bar, or press <kbd>Ctrl</kbd>+<kbd>K</kbd> (<kbd>⌘</kbd>+<kbd>K</kbd> on macOS), then type a title or body keyword to search the docs in the current language. Use <kbd>↑</kbd> / <kbd>↓</kbd> to move between results, <kbd>Enter</kbd> to open one, and <kbd>Esc</kbd> to close search and return to the article. You can also browse articles in the sidebar.
